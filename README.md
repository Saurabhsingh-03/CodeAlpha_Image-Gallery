# 🖼️ Image Gallery

A responsive and interactive **Image Gallery** built using **HTML, CSS, and JavaScript**. This project showcases images in a clean grid layout with navigation controls, hover effects, smooth transitions, and an optional lightbox view for an enhanced user experience.

## 📌 Features

- 🖼️ Responsive image gallery layout
- 🎨 Modern UI with CSS styling
- ✨ Hover effects and smooth transitions
- ⬅️➡️ Previous/Next image navigation
- 🔍 Lightbox view for enlarged image display
- 📱 Fully responsive across devices
- 🏷️ Image filtering by categories (Bonus)
- ⚡ Fast and lightweight implementation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/image-gallery.git
```

### 2. Navigate to the Project Directory

```bash
cd image-gallery
```

### 3. Run the Project

Open `index.html` in your preferred web browser.

## 🎯 Features Breakdown

### Gallery Layout
- Displays images in a responsive grid.
- Automatically adjusts to different screen sizes.

### Lightbox View
- Click an image to view it in an enlarged modal.
- Navigate through images using Next and Previous controls.

### Hover Effects
- Smooth zoom-in effects.
- Image overlays and transition animations.

### Responsive Design
- Optimized for:
  - Desktop
  - Tablet
  - Mobile Devices

### Image Filters (Bonus)
- Filter images based on categories.
- Dynamically update displayed images using JavaScript.

## ⌨️ Optional Keyboard Controls

| Key | Action |
|------|---------|
| ← | Previous Image |
| → | Next Image |
| Esc | Close Lightbox |
